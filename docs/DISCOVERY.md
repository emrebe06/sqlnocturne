# SQLNocturne Discovery

SQLNocturne is a safety-first, JSON-first SQL runtime for Python.

Search phrases this project is built to answer:

- Python SQL runtime
- lightweight SQLAlchemy alternative
- safe SQL query builder
- SQLite runtime for Python
- PostgreSQL and MySQL adapter architecture
- SQL injection guard for Python
- JSON database result object
- native C/C++/Rust SQL safety layer
- Docker and Kubernetes ready Python database library

Related projects:

- QuickAPI: Python API runtime
- Katmer: native C ABI execution layer
